# 星叙 · Storybound

一个使用 DeepSeek 作为主持人的中文单人跑团 RPG。网页与手机共用响应式界面，并提供 PWA 主屏幕入口。

## 开始游玩

需要 Node.js 22 或更高版本。没有第三方运行依赖，无需安装包。

```sh
npm start
```

打开 http://127.0.0.1:3000 。游戏固定由 AI 主持，服务端需要有效的 DeepSeek Key 才能创建或推进剧情。

## 接入 DeepSeek

```sh
cp .env.example .env
```

在 `.env` 中填入：

```dotenv
DEEPSEEK_API_KEY=你的真实Key
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
PORT=3000
HOST=127.0.0.1
```

重新启动服务并刷新页面。所有新冒险与剧情行动固定调用 DeepSeek，前端没有主持模式或模型选择。创建接口无需传入 `mode`，旧 `mode` 参数不能改变主持方式。已有演示存档保留场景、角色与历史，读取时显示 AI 主持，下次成功操作后持久化为 AI 存档。Key 缺失或上游出错时保留原进度并显示错误，不提供演示回退。

默认模型及协议依据 [DeepSeek 模型文档](https://api-docs.deepseek.com/quick_start/pricing/) 和 [JSON Output 文档](https://api-docs.deepseek.com/guides/json_mode/)（核对日期：2026-10-07）。使用 `/chat/completions`、JSON Output 和非思考模式；模型可通过环境变量修改。Key 只保留在后端，游戏上下文会发送至 DeepSeek。模型响应在提交存档前做结构校验；上游失败会显示错误，不自动切换成演示剧情。

本地已按用户提供的 Key 配置，实测 DeepSeek 开场、自由行动、结构化战斗遭遇，以及胜利后的剧情接续成功。Key 保存在被版本控制忽略的 `.env` 中，文件权限为仅所有者可读写；接口与浏览器不会返回该 Key。测试仍使用模拟服务，不消耗 API 额度。

## 当前玩法

- 四种主题：公主与星之冠（童话）、午夜来信（悬疑）、霓虹边界（赛博）、山海旧梦（仙侠）。公主主线配有 AI 生成立绘，其余主题保留 SVG 场景插画。
- 新冒险的主角是漂亮、温柔而勇敢的成年公主，默认名为艾莉娅，可自定义名字；旅人、守护者、学者、吟游者是她的四种天赋方向，具有不同的能力加值。
- 默认主线「公主与星之冠」从加冕前夜开始，围绕母后留下的信、失落的王冠与她对王国未来的选择展开。公主身份、外貌与性格写入服务端角色记录，并传递给 DeepSeek 保持连续性。
- 玩家可以点选行动，或输入最多 500 字的自由行动并选择使用的能力；AI 模式还接受开局故事偏好。
- 后端掷 D20，加上能力值后与难度比较；自然 20 成功，1 失败。难度由当前行动与叙事/经典/挑战模式决定。
- 故事成功获得 10 经验与 3 金币；失败获得 5 经验，并按难度损失 3/5/8 生命。后端控制这些数值，AI 不能任意修改。
- 真实 RPG 背包：生命药剂、魔力药剂、食物、装备与材料具有数量。使用道具后扣除一件，状态已满时不能浪费使用；故事线索独立保留。
- 武器、防具、饰品三种装备栏。细剑、法杖、斗篷、护裙、月石坠等会改变四项能力、攻击、法术或防御；换装与卸装会重新计算，不重复叠加。新角色拥有细剑与斗篷，需要主动装备。
- 每 50 经验升一级，生命上限 +6、魔力上限 +2，获得 1 点可分配天赋，任选四项能力永久 +1。
- 回合制战斗：轻剑攻击、星辉术、治疗祝福、防守回魔与脱身。药剂和技能消耗一回合，对手反击；护甲减少战斗伤害。胜利奖励固定经验、金币和物品，脱身不会获得胜利奖励。体力耗尽可通过续卷休整。
- DeepSeek 根据剧情安排四种敌人模板的遭遇，名称可随主题变化，敌人数值由后端按等级计算。AI 也可安排目录中的物品发现，限成功检定且每卷最多三件；战斗掉落独立按规则计算。已发生的战斗结果与装备、背包一起传给 AI，后续叙事回应实际结果。
- 装备与天赋面板提供「月光演武」：每次 3 金币，胜利获得 8 经验，不掉落物品或金币，生命和魔力消耗保留。
- 随行商会支持买卖装备与补给；已装备的最后一件不能卖出。工坊可以用银叶草调药，用细剑、星尘和金币锻造辉星之剑。
- 除 AI 主线外，探索、魅力与首次战斗任务具有明确进度和一次性奖励，需要主动领取。营地休息花费 8 金币，恢复至多 15 生命和 8 魔力，战斗中不可休息。
- 管理装备、买卖、锻造、领取奖励与战斗不会增加剧情幕数。旧存档会在读取时补充 RPG 初始背包并保留身份、线索和历史；下次成功操作时保存升级后的结构。
- 故事固定由 AI 主持，没有固定回合上限，章节按剧情自然收尾；体力耗尽时暂歇。
- 章节收尾后可输入下一章的方向，休整并继续同一存档，保留公主、经验、金币、物品和过往经历。休整将生命与魔力恢复至上限，不增加经验或金币；DeepSeek 生成下一章开场。已完成的旧演示存档也使用 AI 续写。
- 保存人物、物品、目标、累计记忆与完整旅途记录；模型接收当前场景、最多 32 条累计记忆、最近六次转换摘要和最近十二卷结局摘要以控制上下文。服务器仍保留完整旅途记录；模型接收的是精炼上下文，长期细节连续性取决于累计记忆的质量。
- 导出可阅读故事文本与存档凭据；可在同一服务器的另一台设备导入凭据继续。

预写演示仅保留为内部测试素材，生产接口与玩家界面固定使用 AI 主持。当前图片是主题插画与公主立绘，并非每一幕实时生成图片。公主立绘使用内置 imagegen 生成，已保存到 public/assets/princess-elya.png；完整提示词见 artifacts/princess-image-prompt.txt。

## 手机与存档

同一可信 Wi-Fi 网络内，可将 `.env` 中的 `HOST` 改为 `0.0.0.0`，重启后使用电脑的局域网 IP 与 3000 端口访问。浏览器存档入口不会自动跨设备同步；可通过导出的存档凭据恢复。

PWA 提供 192/512 图标与静态界面缓存；安装到主屏幕通常需要 HTTPS（localhost 例外）。离线无法创建或推进冒险，接口不会被 Service Worker 缓存。当前不包含 iOS/Android 原生安装包。

实际存档写入 `data/sessions.json`，使用临时文件及原子重命名，访问由随机凭据保护。浏览器仅保存存档入口与凭据；不要分享凭据文件。备份时需要保留整个 `data` 文件夹，凭据文件不是完整存档备份。

## 项目结构

```text
server.mjs             HTTP 服务、接口、鉴权、限流与静态文件
lib/catalog.mjs        主题、角色、难度与内部测试剧情
lib/game.mjs           行动校验、掷骰、模型结果校验与状态推进
lib/deepseek.mjs       DeepSeek 调用、主持提示与上下文构建
lib/store.mjs          单进程原子持久化存储
public/app.js          大厅、角色创建、游玩、记录及存档导入导出
public/styles.css     桌面与手机样式
public/assets/        主题插画与 PWA 图标
public/sw.js           静态界面缓存
lib/rpg.mjs           装备、物品、战斗、升级、任务、商会与锻造规则
lib/errors.mjs        共用游戏错误
test/                 后端规则及 HTTP 集成测试
```

这是本机或可信局域网使用的 MVP，默认只监听本机。使用单个 Node 进程运行，同一数据目录不支持多个实例写入。当前没有账号系统、多人组队、跨服务器云存档或实时图像生成。对公网开放前应增加用户登录、按用户 API 配额、数据库和持久化限流，并在 HTTPS 反向代理后部署，避免共享 Key 被匿名消耗。
